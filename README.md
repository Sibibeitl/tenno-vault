# Tenno Vault V4

Diese Version ist aus der stabilen V2-Basis neu aufgebaut. Die fehlerhafte V3 hatte einen zerstoerten Zeilenumbruch in einem Suchmuster, wodurch das gesamte Skript ungueltig wurde.

Enthalten:
- OCR-Texterkennung im Browser
- korrekte Warframe.market-Slugs mit Unterstrichen
- Mehrfachscan mit Sammlung und Chips
- Relikt-Modus mit 5-Sekunden-Timer
- Live-Preise ueber /v2/orders/item/{slug}/top
- Markierung des wertvollsten Gegenstands
- Verkaufen- und Inventar-Knoepfe pro Karte
- gedrosselte Anfragen (360 ms Abstand)
